# Celeste Android experimental sem áudio

[Baixar APK](https://github.com/tgparkinguniversal-hue/celeste/raw/refs/heads/main/celeste-download/celeste-android-silent-test-v0.5.apk)

Os dados estão divididos em partes por causa do limite de tamanho do GitHub. A página index.html baixa e verifica cada parte e oferece o ZIP completo. O APK exige esse ZIP em Importar dados originais. Ainda não validado em aparelho Android.

Na v0.5, use LOG para abrir/fechar o painel de mensagens; arraste o cabeçalho para movê-lo. Ajustado o ciclo de vida de inicialização Android. Instale por cima, sem desinstalar, para preservar os dados importados.
